# MoneyNote Lite

Ứng dụng ghi chép thu chi đơn giản, dùng để thực hành Git.

Mở `index.html` bằng trình duyệt để chạy.

## Cấu trúc thư mục

```
index.html        Giao diện
css/style.css     Giao diện
js/tinh-toan.js   Các hàm tính tổng, định dạng tiền
js/app.js         Hiển thị dữ liệu lên trang
kiem-tra.js       Kiểm tra nhanh hàm tính tổng: node kiem-tra.js
```

## Cách kiểm tra

Chạy lệnh sau để kiểm tra các hàm tính toán:

    node kiem-tra.js

Kết quả đúng là in ra ĐẠT.
